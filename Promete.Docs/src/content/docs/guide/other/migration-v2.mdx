import { Aside, Tabs, TabItem } from '@astrojs/starlight/components';

このガイドでは、Promete v1 から v2 へコードを移行する際に必要な変更点を解説します。

<Aside type="tip">
v2 では `IWindow` に `[Obsolete]` 属性が付与され、`CompatibleWindow` による後方互換ラッパーが提供されています。
そのため、既存のコードはビルド警告が出るものの、すぐに動かなくなるわけではありません。
ただし、新しいAPIへの移行を推奨します。
</Aside>

## 対象ランタイムの変更

v2 では対象ランタイムが **.NET 8** から **.NET 10** に変更されました。

```xml
<!-- v1 -->
<TargetFramework>net8.0</TargetFramework>

<!-- v2 -->
<TargetFramework>net10.0</TargetFramework>
```

## アプリケーション開発者向けの変更

### アプリの初期化

初期化コードに変更はありません。`BuildWithOpenGLDesktop()` は引き続き使用できます。

```csharp
var app = PrometeApp.Create()
    .Use<Keyboard>()
    .Use<Mouse>()
    .Use<Gamepads>()
    .BuildWithOpenGLDesktop();

return app.Run<MainScene>(WindowOptions.Default with
{
    Title = "My Game",
});
```

### IWindow の分割: IGameView と ITimeProvider

v1 では `IWindow` がウィンドウ表示・時間管理・イベントなどを一手に担っていましたが、v2 ではこれらが分割されました。

| 用途 | v1 | v2 |
|------|----|----|
| ウィンドウ表示・サイズ・状態 | `IWindow` | `IGameView` |
| フレーム時間・FPS | `IWindow` | `ITimeProvider` |

Scene からは `View` と `Time` プロパティで直接アクセスできます。

<Tabs>
  <TabItem label="v1">
```csharp
public class MainScene(IWindow window) : Scene
{
    public override void OnUpdate()
    {
        var dt = window.DeltaTime;
        var size = window.Size;
        window.Title = "My Game";
    }
}
```
  </TabItem>
  <TabItem label="v2">
```csharp
public class MainScene() : Scene
{
    public override void OnUpdate()
    {
        var dt = Time.DeltaTime;
        var size = View.Size;
        View.Title = "My Game";
    }
}
```
  </TabItem>
</Tabs>

#### IGameView の主要メンバー

```csharp
public interface IGameView
{
    VectorInt Location { get; set; }
    VectorInt Size { get; set; }
    VectorInt ActualSize { get; }
    int Scale { get; set; }
    bool IsVisible { get; set; }
    bool IsFocused { get; }
    bool IsFullScreen { get; set; }
    float PixelRatio { get; }        // Retinaディスプレイ対応
    string Title { get; set; }
    WindowMode Mode { get; set; }
    Texture2D TakeScreenshot();
    Task SaveScreenshotAsync(string path, CancellationToken ct = default);
    event Action<FileDroppedEventArgs>? FileDropped;
    event Action? Resize;
}
```

#### ITimeProvider の主要メンバー

```csharp
public interface ITimeProvider
{
    float TotalTime { get; }
    float DeltaTime { get; }
    long FramePerSeconds { get; }
    int TargetFps { get; set; }
    float TimeScale { get; set; }     // 新機能: 時間のスケーリング
}
```

### Angle 構造体の導入

ノードの回転角度が `float` から `Angle` 構造体に変更されました。`float` との暗黙的な変換が用意されているため、多くの場合は既存コードがそのまま動作します。

<Tabs>
  <TabItem label="v1">
```csharp
sprite.Angle = 90f;
sprite.Angle += 1f;
float angle = sprite.Angle;
```
  </TabItem>
  <TabItem label="v2">
```csharp
// 暗黙変換があるのでそのままでもOK
sprite.Angle = 90f;
sprite.Angle += 1f;
float angle = sprite.Angle;

// 新しい機能: 明示的な単位指定
sprite.Angle = Angle.FromDegrees(90);
sprite.Angle = Angle.FromRadians(MathF.PI / 2);
float rad = sprite.Angle.Radians;
```
  </TabItem>
</Tabs>

### Material とシェーダー（新機能）

v2 では、ノードにシェーダーエフェクトを適用できるようになりました。

#### 基本的な使い方

```csharp
// 1. シェーダープログラムを作成
var shader = ShaderProgram.Create()
    .Vertex(vertexGlsl)
    .Fragment(fragmentGlsl)
    .Compile();

// 2. マテリアルを作成
var material = new Material(shader);

// 3. uniform変数を設定
material["uTime"] = 1.0f;

// 4. ノードに適用
sprite.Material = material;
```

#### 画面全体へのポストエフェクト

```csharp
App.PostProcessMaterials.Add(material);
```

複数のマテリアルを追加すると、順番にチェーン適用されます。

<Aside type="caution">
`ShaderProgram` は `IDisposable` です。不要になったら `Dispose()` を呼んでください。
</Aside>

### FrameBuffer の変更

v2 では `FrameBuffer` に手動レンダリングや自動クリアの制御が追加されました。

```csharp
var fb = new FrameBuffer(320, 240);

// 新プロパティ
fb.AutoRender = false;  // 自動レンダリングを無効化
fb.AutoClear = false;   // 自動クリアを無効化

// 手動でレンダリングを実行
fb.Render();

// テクスチャの取得（読み取り専用に変更）
var texture = fb.Texture;
```

### TextureFactory の参照先変更

テクスチャファクトリの取得先が変わりました。

<Tabs>
  <TabItem label="v1">
```csharp
var texture = Window.TextureFactory.Load("image.png");
```
  </TabItem>
  <TabItem label="v2">
```csharp
var texture = App.TextureFactory.Load("image.png");
```
  </TabItem>
</Tabs>

----

加えて、コンストラクタ経由で取得することもできます。

```csharp
public class TheScene(TextureFactoryBase textureFactory) : Scene
{
    private Texture2D _texture;

    public override void OnStart()
    {
        _texture = textureFactory.Load("./path/to/texture.png");
    }

    public override void OnDestroy()
    {
        _texture.Dispose();
    }
}
```

### Texture2D の UV 座標サポート（新機能）

`Texture2D` に UV 座標を表すプロパティ `UvStart` `UvEnd` を追加しました。

これに伴い、スプライトシートを読み込んだときに、同じソースの場合は同じテクスチャハンドルを参照し、UV値のみが異なる `Texture2D` が生成されるようになりました。

## プラグイン開発者向けの変更

### バックエンドアーキテクチャの刷新

v1 では `IWindow` を直接実装してバックエンドを構成していましたが、v2 では `BackendBase` 抽象クラスを継承し、各責務を個別のインターフェースで実装する方式に変更されました。

```csharp
public abstract class BackendBase
{
    public abstract void OnInitialize(PrometeApp app, WindowOptions windowOptions);
    public abstract ITimeProvider SetupTimeProvider();
    public abstract IGameView SetupGameView();
    public abstract InputProvider SetupInputProvider();
    public abstract IScreenBlitter SetupScreenBlitter();
    public abstract TextureFactoryBase SetupTextureFactory();
    public abstract IRenderTextureProvider SetupRenderTextureProvider();
    public abstract IShaderFactory SetupShaderFactory();
    public abstract void OnStart(PrometeApp app);
    public abstract void OnExit(PrometeApp app);
}
```

各メソッドで返すインターフェースを実装することで、バックエンドの各機能を構築します。

| メソッド | 返す型 | 責務 |
|----------|--------|------|
| `SetupGameView()` | `IGameView` | ウィンドウ表示・サイズ管理 |
| `SetupTimeProvider()` | `ITimeProvider` | フレーム時間・FPS管理 |
| `SetupInputProvider()` | `InputProvider` | 入力デバイスのコンテキスト提供 |
| `SetupScreenBlitter()` | `IScreenBlitter` | 画面レンダリングとポストエフェクト |
| `SetupTextureFactory()` | `TextureFactoryBase` | テクスチャの読み込み |
| `SetupRenderTextureProvider()` | `IRenderTextureProvider` | RenderTexture の生成・管理 |
| `SetupShaderFactory()` | `IShaderFactory` | シェーダーのコンパイル |

バックエンドの登録は `Build<T>()` メソッドで行います:

```csharp
var app = PrometeApp.Create()
    .Use<Keyboard>()
    // ...
    .Build<MyCustomBackend>(opts);
```

### NodeRenderer の廃止

v1 では各ノードタイプに対して `NodeRenderer` クラスを実装し、`UseRenderer<TNode, TRenderer>()` で登録していました。

v2 ではこの仕組みが完全に廃止され、ノード自身が `Collect()` メソッドでレンダリングコマンドを生成する方式に変わりました。

<Tabs>
  <TabItem label="v1">
```csharp
// カスタムノード
public class MyNode : Node { ... }

// レンダラーの実装
public class MyNodeRenderer : NodeRendererBase
{
    public override void Render(Node node) { ... }
}

// 登録
app.UseRenderer<MyNode, MyNodeRenderer>();
```
  </TabItem>
  <TabItem label="v2">
```csharp
// カスタムノードが直接レンダリングコマンドを生成
public class MyNode : Node
{
    internal override void Collect(RenderCommandQueue queue, RenderContext ctx)
    {
        // レンダリングコマンドをキューに追加
        queue.Enqueue(new DrawTextureCommand
        {
            Texture = _texture,
            Location = AbsoluteLocation,
            Scale = AbsoluteScale,
            Angle = AbsoluteAngle,
            // ...
        });
    }
}
```
  </TabItem>
</Tabs>

### レンダリングコマンドシステム

v2 のレンダリングは、コマンドキュー方式で動作します。

#### コマンドの種類

| コマンド | 用途 |
|----------|------|
| `DrawTextureCommand` | テクスチャ描画（自動バッチング対応） |
| `DrawPrimitiveCommand` | プリミティブ図形の描画 |
| `DrawPieTextureCommand` | 扇形テクスチャの描画 |
| `BeginTrimCommand` / `EndTrimCommand` | シザーテスト（描画範囲の制限） |
| `BeginStencilMaskCommand` / `EndStencilMaskCommand` | ステンシルマスク |
| `BeginAlphaMaskCommand` / `EndAlphaMaskCommand` | アルファマスク |

#### CommandRunner

各コマンドの実行は `CommandRunner<T>` クラスが担います。バックエンド固有のレンダリング処理はここに実装します。

```csharp
// RenderCommandQueue にランナーを登録
app.GetPlugin<RenderCommandQueue>().RegisterRunnerRange(
    app.GetPlugin<GLDrawTextureBatchedCommandRunner>(),
    app.GetPlugin<GLDrawPrimitiveCommandRunner>(),
    // ...
);
```

### TextureFactory の名称変更

`TextureFactory` クラスは元々抽象クラスでしたが、その名称を `TextureFactoryBase` に変更しました。

### IScreenBlitter

画面全体のレンダリングとポストエフェクトの適用を担う新しいインターフェースです。

```csharp
public interface IScreenBlitter
{
    RenderTexture ScreenRenderTexture { get; }
    void BlitToScreen(IReadOnlyList<Material> materials);
}
```

### IShaderFactory

シェーダーのコンパイルとデフォルトシェーダーの生成を担います。

```csharp
public interface IShaderFactory
{
    void Compile(ShaderProgram program);
    ShaderProgram CreateDefault();
}
```

### IRenderTextureProvider

`IFrameBufferProvider` から名前が変更され、API も整理されました。

```csharp
public interface IRenderTextureProvider
{
    RenderTexture Create(VectorInt size);
    IDisposable BeginCapture(RenderTexture rt, Color? clearColor);
    void Resize(RenderTexture rt, VectorInt newSize);
    void Release(RenderTexture rt);
}
```

## 名前空間の変更一覧

v2 ではレンダリング関連のクラスを中心に、名前空間の大幅な再編が行われました。

### 移動された型（リネーム含む）

| 型名 | v1 の名前空間 | v2 の名前空間 | 備考 |
|-------|--------------|--------------|------|
| `TextureFactoryBase` | `Promete.Graphics` | `Promete.Graphics` | クラス名が `TextureFactory` → `TextureFactoryBase` に変更 |
| `GLTextureFactory` | `Promete.Windowing.GLDesktop` | `Promete.Windowing.GLDesktop` | クラス名が `OpenGLTextureFactory` → `GLTextureFactory` に変更 |
| `CoordinateExtension` | `Promete.Nodes.Renderer` | `Promete.Graphics.Rendering` | |
| `RenderingHelper` | `Promete.Nodes.Renderer` | `Promete.Graphics.Rendering` | |
| `GLHelper` | `Promete.Nodes.Renderer.GL.Helper` | `Promete.Graphics.Rendering.GL` | |
| `GLMaskedContainerHelper` | `Promete.Nodes.Renderer.GL.Helper` | `Promete.Graphics.Rendering.GL` | |
| `GLDrawPieTextureCommandRunner` | `Promete.Nodes.Renderer.GL.Helper` | `Promete.Graphics.Rendering.GL.Runners` | クラス名が `GLPieSpriteRendererHelper` から変更 |
| `GLDrawPrimitiveCommandRunner` | `Promete.Nodes.Renderer.GL.Helper` | `Promete.Graphics.Rendering.GL.Runners` | クラス名が `GLPrimitiveRendererHelper` から変更 |
